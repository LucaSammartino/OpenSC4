# Network-rule observation ABI (GOG 1.1.641)

Private interoperability facts for the record-only boundary specified in
[network-rules.md §2.5](../specs/network-rules.md#25-native-observation-contract-nr16-gog-11641).
These are not new GZCOM interfaces or C ABI exports. Addresses below are preferred image VAs;
all pointers and stack argument slots are 4 bytes. Behaviour and capture policy belong to the spec.

## Image identity and exact entry bytes (NR17)

Reference file: GOG Deluxe 1.1.641 `SimCity4.exe`, whole-file SHA-256
`3bc5c7fe807fe5aa24a3abb06e40f13486670bc1150612c09baf4ecedafe1a4b`.

| PE field | Value |
|---|---|
| Machine | `0x014C` (32-bit x86) |
| TimeDateStamp | `0x4C12BFB7` |
| ImageBase / SizeOfImage | `0x00400000` / `0x007C8000` |
| File Characteristics | `0x010F`, including RELOCS_STRIPPED |
| DLL Characteristics | `0x0000`, no DYNAMIC_BASE |
| Base relocation directory RVA / size | `0` / `0`; no base-relocation entries |

Each byte string is in increasing memory-address order. Span lengths include only whole instructions;
continuation is the first undisplaced instruction. For this file the three RVAs also equal their file offsets.

| Entry | VA | RVA / file offset | Length | Exact expected bytes | Instruction lengths | Continuation VA |
|---|---|---|---|---|---|---|
| Evaluate | `0x006220D0` | `0x002220D0` | 5 | `53 8B 5C 24 0C` | 1, 4 | `0x006220D5` |
| ReloadRules | `0x006253D0` | `0x002253D0` | 6 | `81 EC 80 00 00 00` | 6 | `0x006253D6` |
| Static cleanup callback | `0x006232F0` | `0x002232F0` | 5 | `A0 A8 52 B4 00` | 5 | `0x006232F5` |

None of these spans has a relative call, jump or instruction-pointer-relative operand. Evaluate and ReloadRules
have no address operand requiring relocation. Cleanup has a 4-byte **absolute** operand at `0x006232F1`
(span offset 1), value `0x00B452A8`, the process flag. It is not PC-relative, and the PE supplies no relocation
for it. When copying this span to a trampoline with the game at its required base, retain that operand exactly:
it still addresses the game's flag. Do not add the trampoline displacement or mask these four bytes.
The later cleanup flag-write operand at `0x006232FD` also contains `0x00B452A8`, but is outside the displaced span.

The supported reference requires loaded module base **exactly `0x00400000`**. It does not authorize rebasing or
synthesizing relocated references for a different loaded base. Require the file fingerprint and compare every
byte of all three loaded spans to the table before installing this observation set. PE identity and executable-page
membership alone do not check these bytes. Reject any mismatch, including a pre-existing jump or a changed
absolute operand; there are no wildcard bytes. Validate again under the serialization that protects installation
from execution or modification at these sites. A patch must consume exactly the listed whole span and resume at
the listed continuation, preserving the original stack/register/flag effects of the displaced instructions.
The continuation jump generated by the hook is separate from these original spans.

Evidence: export instruction bytes at `0x006220D0`–`0x006220D5`, `0x006253D0`–`0x006253D6`, and the complete
cleanup function `0x006232F0`–`0x00623302`, queried with `tools/re_query.py asm --bytes`; independent read-only
PE file reads confirmed all three strings, the fingerprint and relocation-directory facts on 2026-10-23.
These are validated boundaries, not a claim that a hook has been installed or tested in-game.

## Native calls (NR16 publication)

Arguments are in declaration order. For thiscall, ECX is the original object base, not another interface subobject;
the callee pops the listed argument bytes. A metaposition is the low byte of its 4-byte slot. A bool argument
also occupies a full slot. For cdecl entries there is no `this` or stack argument here.

| Address | Convention | This | Arguments | Pops | Return |
|---|---|---|---|---|---|
| `0x006220D0` | thiscall | evaluator base | neighbourhood pointer; pointer to writable result-pointer slot | 8 | bool in AL; upper EAX unspecified; borrowed descriptor through slot |
| `0x00621D30` | thiscall | neighbourhood base | metaposition; u32 output pointer | 8 | word through output pointer; ignore EAX |
| `0x00627080` | thiscall | writable 0x28-byte neighbourhood | signed x; signed z; original tool base; type index; override bool | 20 | this in EAX |
| `0x006253D0` | cdecl | none | none | 0 | void; no load-success status |
| `0x006232F0` | cdecl | none | none | 0 | AL=1, upper EAX unspecified |
| `0x00633220` | thiscall | original tool base | packed cell key | 4 | cell-info pointer in EAX; may populate cache |

Evaluate is non-virtual. The caller owns only its 4-byte result-pointer slot. A successful result points to a
12-byte vector descriptor, not the first output element. No-match gives AL=0 and a null slot; matched-empty
gives AL=1 and a non-null descriptor with begin=end. Neither descriptor nor buffer may be freed by the caller.
ReloadRules and cleanup are process-wide boundaries, not evaluator instance methods. A cleanup return must
preserve AL=1 even if the incoming process flag was zero; it is not the previous flag or a success/failure report.

## Neighbourhood virtual calls

The 0x28-byte original neighbourhood has vtable `0x00AA8700`; it is not reference counted. Neither entry is a destructor.

| Slot | Byte offset | Target | Convention | Arguments | Pops | Return |

## Private layouts

These are 32-bit game layouts, independent of host compiler containers. A vector descriptor is three pointers:
begin, end, storageEnd; only [begin,end) contains elements. All three may be null for an empty vector.

| Owner | Offset | Field / type |
|---|---|---|
| network-type record, `0x00B452C8 + type*0x114` | `+0x24/+0x28/+0x2C` | evaluator-pointer vector begin/end/storageEnd; stride 4 |
| evaluator, size 0x10 | `+0/+4/+8` | vtable `0x00AA8338`; tree-header pointer; node count |
| tree node/header, size 0x34 | `+0` | colour byte; padding follows |
| tree node/header | `+4/+8/+0xC` | parent/left/right pointers; header parent=root; header left=min; header right=max |
| ordinary tree node | `+0x10/+0x14` | unsigned map key / rule centre word |
| ordinary tree node | `+0x18/+0x1C/+0x20` | conditions begin/end/storageEnd |
| ordinary tree node | `+0x24/+0x28/+0x2C` | outputs begin/end/storageEnd |
| ordinary tree node | `+0x30` | transform eligibility byte; padding follows |
| standalone rule, size 0x20 | `+0/+4/+0x10/+0x1C` | centre word / condition vector / output vector / eligibility byte |
| condition element, stride 12 | `+0/+4/+8` | metaposition byte / expected u32 / mask u32; padding +1..3 |
| output element, stride 8 | `+0/+4/+5` | piece u32 / metaposition byte / orientation byte; padding +6..7 |
| neighbourhood, size 0x28 | `+0/+4` | vtable `0x00AA8700` / centre word |
| neighbourhood | `+8/+0xC/+0x10` | cache vector begin/end/storageEnd; stride 12 |
| neighbourhood cache element | `+0/+4` | metaposition byte / cached u32; remaining bytes not semantic |
| neighbourhood | `+0x14/+0x18/+0x1C/+0x20/+0x24` | signed x / signed z / tool-base pointer / type index / invalid-type mask |
| cell info | `+8 / +0x18 + 4*type` | flags u32 / type edge word u32 |
| global cIntRule map, `0x00B452B0` | `+4/+8/+0xC/+0x10` | bucket begin/end/storageEnd / node count |
| global-map node, size 0x104 | `+0/+4/+8` | next pointer / unsigned id / 0xFC-byte value |
| global process flag, `0x00B452A8` | `+0` | byte; not a load-completion indicator |

An empty tree header has parent=null and left=right=header; ordinary missing children are null and root.parent
is header. Header payload is uninitialized. A bucket is a 4-byte node pointer. The global map's value owns its
subordinate storage; its tile/tag submaps are separate containers.

All rule/tree/output/map storage is borrowed and may be invalidated by reload, clear or destruction.
Neighbourhood and cache storage lasts only for the original solver operation. No AddRef/Release or background
traversal contract exists. Only detached semantic copies may outlive the synchronous observation; instrumentation
must preserve native ABI state, return registers and floating-point state.

NR16 evidence and semantic rules: spec §2.5.1–§2.5.4, including constructors/copies `0x00622AB1`–`0x00622ACA`,
`0x00622205`–`0x0062222F`, `0x006224B9`–`0x006224EB`; neighbourhood accessors `0x00621D30`–`0x00621DDF`,
`0x00623EE0`–`0x00623F97`, initializer `0x00627080`–`0x006270F1`; map allocation/lookup
`0x0062C171`–`0x0062C1D2`, `0x0062C2F0`–`0x0062C337`. This publishes the NR16 private contracts alongside NR17's
validated byte reference; the existing shared TSV rows are not regenerated.
