# Occupants and props: contract index

The behavior contracts for this group live in:

- [Lot and occupant records](lot-records.md): saved records and the behavior of the individual occupants.
- [City-detail text decal](text-decal-occupant.md): corrected receiver frames, owned label state,
  resource/geometry/lifetime order and [unexecuted vectors](text-decal-vectors.md).
- [Occupant manager](occupant-manager.md): occupant queries and filters.
- [Prop and lot configuration managers](prop-lotconfig.md): catalogue and city queries.

The shared OP questions are in [questions/occupants-props.md](questions/occupants-props.md).
This index connects that question file to its canonical contracts; it adds no behavior of its own.
