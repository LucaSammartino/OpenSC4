- **HD1** §3 DumpUnhandledAttributes: does the per-entry walk (008ff7e7) have any observable effect in the shipping build (log output, state)? [current: none; reimplement as a no-op]
  **ANSWERED 2026-10-21 (re-htmldocument4):** MATCHES — DumpUnhandledAttributes only advances a map iterator from begin to end (008ff7e7/008ff123/008fe87e are pure reads); no output, no state change; its two arguments are unused. Spec §3.
- **HD2** §5.4 byte 0x154: ParseTextDocument sets it to 1 before inserting the plain text, Init clears it. Is it the preformatted/no-wrap flag read by cHTMLTextSegment, or something else? [current: treat as "preformatted", only set by ParseTextDocument and the PRE path]
  **ANSWERED 2026-10-21 (re-htmldocument4):** MATCHES — 0x154 is field +0x24 of the style record (0x130..0x157), saved/restored by push/pop; the text-segment ctor (00908ce2/00908ea5) passes it to FixTextSegmentWhitespace: 0 collapses whitespace runs to one space, 1 keeps text and normalises CR/CRLF/LF to LF. Set by ParseTextDocument and PRE (00906a74). Spec §5.4.
- **HD3** §3 ParseAttributeList: after taking a name/value, there is a step that removes a leading and trailing `"` from one of the two strings when both ends are quotes (009056da, around the MakeUpper call). Which string (name or value) does it apply to? [current: unverified; values from quoted syntax never carry quotes anyway]
  **ANSWERED 2026-10-21 (re-htmldocument4):** DIFFERS — it applies to the NAME (string at EBP-0x34, then MakeUpper), deletes index 1 and the last char (erase(1,1), erase(len-1,1)); given the name grammar it only fires for the 1-char name `"`, which becomes empty, and empty names are not inserted (00905902). Spec §3 steps 6-7.
- **HD4** §9 ResourceHasBeenDownloaded: for a record whose byte +0x2c is 0, which bytes are written to the temp file (the local string filled around 0096edf7/00919b00 vs the record's buffer at +0x30), and what path is used when +0x2c is 1? [current: in-memory data -> temp file; file record -> its own path]
  **ANSWERED 2026-10-21 (re-htmldocument4):** MATCHES — +0x2c==0: the +0x30 string holds the bytes; they are swapped (0096edf7) into a local and written verbatim (length end-begin) to a fresh MakeTempPathName file opened write/create-always/exclusive (00919b00(2,1,0)), loaded, then removed. +0x2c!=0: +0x30 is used as the path, nothing written/removed. Spec §9.
