- **PT6 - §6 rest of `Start` `0x005B3000`:** after `preferSea`: the loop-interval countdown `+0x190`, the emission volume, the preroll byte `+0x118`, and the order of every `RandomRange` draw (which generator `0x00913761` uses). **ANSWERED 2026-10-21 (re-particles4):** MATCHES — particles.md §6 steps 4-7: generator 0x00B22DF8 (RandomDoubleRangeUniform = lo + u(hi-lo)); preferSea picks a sea-access direction from GetCellSeaAccess and transforms it by +0xC8 / +0xF8; countdown +0x190 := draw(+0x20,+0x24) if +0x20 >= 0, else draw(+0x28,+0x2C) if +0x28 >= 0, else 0; +0x188 := mode, +0x18C := 0, preroll byte +0x118 := (mode != 0). The emission volume is set by SetDescription (§6.1), not Start.
