# UI feedback owners: open questions

## UIFO-1 — Exact foreign string grammar

Spec: [ui-feedback-owners §3.3](../ui-feedback-owners.md#33-text-branch-raw-string-boundary).
What exact SplitToken/Find character and resource-string semantics are needed
for end-to-end text vectors? The current owner contract takes the single raw
primitive outputs and proves the branch and call order; it does not invent a
tooltip target cache or foreign text renderer.

## UIFO-2 — Progress unnamed destruction and repaint details

Spec: [ui-feedback-owners §2](../ui-feedback-owners.md#2-ownership-and-body-ledger).
Which unnamed table entries are actually Progress-owned teardown and update
bodies, and what ordinary-return paths do they establish? Five attributed names
do not prove vtable extent or whole-object completion. No generic percentage,
monotonic update, modal pumping or restored window state is currently qualified.
